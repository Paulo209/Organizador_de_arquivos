# ![icon](./icon.ico) Organizador de Arquivo 
Uma programa em **python** que organizar os arquivos de uma pasta pela extensão dos arquivos, separando em pasta como Video, Audio, Documentos...

Bibliotecas utilizadas no projeto:
- **Nativas**: [os, sys, pathlib, json, shutil, logging],
- **PyInstaller**


### Passo a passo de como baixar e usar 

1.  Baixe o [organizador.exe](./dist/) dentro da pasta dist
2.  Inicie o programa e informe o caminho da pasta que deseja organizar "C:\Users\Exemplo\Downloads"

Após prosseguir o programa vai organizar os arquivos e criar um log registrando o processo. 
Nesse mesmo log vai ter uma lista de arquivos no qual a extensão não esta registrado no config
